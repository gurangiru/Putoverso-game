# PUTOVERSO — versão 0.7

## Correções e novidades
- Corrigido o preenchimento do fundo no zoom/fullscreen para evitar faixas e áreas vazias.
- Cavalinhos viram automaticamente para encarar a Alpaca.
- Ondas sonoras agora têm munição limitada: 5 disparos.
- Cada CD coletado recarrega a munição para 5 disparos.
- Acertar um cavalinho com uma onda sonora o deixa desacordado por alguns segundos, com indicação visual “Zz”.
- HUD mostra a quantidade de ondas disponíveis.
