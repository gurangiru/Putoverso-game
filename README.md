# PUTOVERSO — Alpaca Colorida

Protótipo jogável da primeira fase, Campos da Desarmonia.

## Controles
- Setas esquerda/direita ou A/D: mover
- Segurar seta para baixo ou S: agachar e andar agachada
- Espaço, W ou seta para cima: pular
- X: disparar Onda Sonora
- ↻ Reiniciar: reiniciar a fase
- ⛶ Tela cheia: ampliar a área de jogo e solicitar orientação horizontal quando o navegador permitir
- R: reiniciar pelo teclado

No celular, os botões de toque permanecem visíveis no modo de tela cheia, inclusive depois de girar para paisagem. O bloqueio automático de orientação depende do suporte e das permissões do navegador.

## Publicar no GitHub Pages
Substitua `index.html` e `README.md` na raiz do repositório pela versão atualizada e aguarde o GitHub Pages concluir a publicação.

Este protótipo usa Canvas e JavaScript puro, sem bibliotecas externas.
